# 3.1 The Planning Model (`M.plans`)

## Problem
The APLRET framework strictly introduces an explicitly sequenced cognitive layout for multi-step reasoning capabilities via `M.plans` which is entirely unmodeled right now. `goalState` exists but isn't tied effectively to a hierarchical cursor loop.

## Action Items
- Implement `M.plans: { plans: Record<PlanId, Plan>; activePlanId?: PlanId }`.
- Route LLM plan generation completely through `Execution` (creating intents for `create_plan` and `repair_plan`).
- Expand `Perception` and `Learning` to validate explicit standard internal schema shapes (`internal/plan.proposed` -> update cursor and step status).
