# 3.5 Canonical LLM Output Contracts (Enforced)

## Problem
The rule mandates: "Structured LLM output must be contracted via JSON Schema/Zod internally". The current loop arbitrarily allows LLM calls to fail open or quietly leak schema violations back locally without structured tracking.

## Action Items
- Wrap LLM extraction/schema execution boundaries with strict Zod/JSON-Schema error validations.
- Catch miss-hits inside `Execution` natively, transforming failure states directly into `internal/validation.failed` inbox observations.
- Allow `Learning` layers to detect these traces and decide strictly between retry limits, plan-reparation triggers, or returning an `ask_user` interaction boundary.
