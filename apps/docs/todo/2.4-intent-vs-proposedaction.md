# 2.4 `Intent` vs `ProposedAction` Naming & Shape

## Problem
The `Intent` typing across the codebase is disjointed from the APLRET contract payload envelopes. `oneTurn.ts` uses an ambiguously-defined `ProposedAction` type bridging internal actions (`subagent`, `language`) with standard interactions (`tool`).

## Action Items
- Deprecate `ProposedAction` in favor of a strictly discriminated `Intent` type.
- Align fields (`call_tool`, `delegate_to_child`, `create_plan`, `answer_with_llm`) with exact contract definitions.
- Refactor intent dispatch boundaries in `Execution` routing modules smoothly.
