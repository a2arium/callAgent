# 2.3 Learning Single-Writer Rule Violations

## Problem
Framework runners (`TurnRunner.ts` and `TaskExecutor.ts`) manually inject `llmState` directly into `M.memory.sensory` during their context persistence flush mechanism. This silently bypasses the rule that only `Learning` has write access to `MentalState`.

## Action Items
- Eliminate manual injections of `llmState` inside the turn persistence mechanics.
- If LLM context must be persisted to cognition, expose it as an observation so `Learning` can naturally save it to sensory memory.
