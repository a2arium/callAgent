# 5.4c — Migration (incremental)

Phase **4c** adds optional **NATS JetStream** transport for `IEventBus` + `MessageLog`, adapter resolution in core, and a typed **`AdapterError`** surface for startup failures.

## Optional package

Add **`@a2arium/callagent-eventbus-nats`** to the **host application** when you select `adapter: "nats"` (it is not a dependency of `@a2arium/callagent-core`).

- **`@a2arium/callagent-eventbus-nats`** (`packages/eventbus-nats`) — production-oriented adapters:
  - **`NatsJetStreamEventBus`** — Core NATS pub/sub for `BusEvent` envelopes (optional dispatch-pressure hooks via **`NatsEventBusDispatchPressure`** / core **`BackpressureManager`**).
  - **`NatsJetStreamMessageLog`** — JetStream stream + KV idempotency index for `MessageLog`.
  - **`createNatsTransportAdapters`**, **`createNatsJetStreamEventBusStandalone`** — shared-connection factories.

Durable replay on NATS bundles uses **`createNatsJetStreamDurableSubscription`** (alias of **`createInProcessDurableSubscription`**) from **`@a2arium/callagent-core`** with your `SessionManager` (or other store) as **`DurableSubscriptionPersistence`**.

## Runtime config shape

Validated by **`TransportAdapterConfigSchema`** (`packages/core/src/orchestration/AdapterFactory.ts`):

```json
{
  "eventBus": { "adapter": "nats", "nats": { "servers": ["nats://host:4222"] } },
  "messageLog": {
    "adapter": "nats",
    "nats": {
      "servers": ["nats://host:4222"],
      "stream": "CALLAGENT_MSGLOG",
      "idempotencyKvBucket": "CALLAGENT_MSGLOG_IDEMP"
    }
  }
}
```

- **`messageLog.adapter: "nats"`** requires **`eventBus.adapter: "nats"`** (topic stream fan-out uses the same broker).
- **`in-memory`** / **`database`** message log adapters both use **`createDbMessageLog(SessionManager)`** today; the session store (RAM vs SQL) is chosen separately via `TaskEngine` / `WorkingMemorySessionStore`.

## Composition

1. **`await resolveTransportAdapters({ transport, sessionManager })`** → `{ eventBus, messageLog, createDurableSubscription, close }`.
2. **`new TaskEngine({ sessionStore, eventBus, messageLog, createDurableSubscription, transportClose: close, ... })`**.

`TaskEngine` always wraps `messageLog` with **`wrapMessageLogWithTopicStream`**. Call **`await taskEngine.closeTransportAdapters()`** on shutdown when `close` was supplied.

## Errors

- **`AdapterError`** — closed discriminated union (`AdapterNotInstalled`, **`AdapterUnknown`** for adapter ids outside the registry, `AdapterConfigInvalid`, `AdapterConnectFailed`, `AdapterVersionIncompatible`).
- Thrown as **`AdapterErrorThrowable`** with a **`.body`** payload (narrow on `kind`).

## Broker integration tests

- Set **`RUN_BROKER_TESTS=1`** and optional **`NATS_URL`** (comma-separated). Without this, NATS tests are **skipped** in CI by default.
- **`packages/eventbus-nats/tests/contract.test.ts`** starts a JetStream **`NatsContainer`** when **`NATS_URL`** is unset (requires Docker). **`@testcontainers/nats`** is a root dev dependency.

## Kafka

Per phase plan, **Kafka** is **not** implemented; see `apps/docs/todo/5.4-deferred-kafka-adapter-implementation-spec.md`.
