# Migration: 5.1 Conversation Phase 1 Thread Primitives

## Overview

Phase 5.1 introduces thread-native conversation APIs on `TaskContext`:

- `ctx.conversation.startThread(...)`
- `ctx.conversation.send(...)`
- `ctx.conversation.close(...)`

It also introduces `source: 'conversation'` observations and optional conversation metadata in `TurnTrace`.

## No Backward Compatibility Notice

This phase does not provide compatibility shims for ad-hoc conversation payloads.  
Only the typed contracts exported from `@a2arium/callagent-core` are supported.

## Before / After

Before (child-only delegation shape):

```ts
const handle = await ctx.sendTaskToAgent('child-agent', input, { awaitCompletion: false });
return { kind: 'await_child', token: handle.token };
```

After (thread-native conversation):

```ts
const started = await ctx.conversation.startThread({
  targetAgentId: 'child-agent',
  message: {
    senderAgentId: ctx.agentId,
    speechAct: 'request',
    content: { task: 'analyze-input' },
  },
});

const sent = await ctx.conversation.send(
  started.thread,
  {
    senderAgentId: ctx.agentId,
    recipientAgentId: 'child-agent',
    speechAct: 'question',
    content: { clarifyingQuestion: 'Need stricter constraints?' },
  },
  { queueMode: 'reject' }
);
```

## Observation Migration

Conversation delivery enters the inbox as:

- `source: 'conversation'`
- `kind: 'message.received' | 'delivery.failed' | 'thread.closed'`

Update perception normalizers and tests to handle this branch through the canonical inbox pipeline.

## Trace Migration

`TurnTrace` may now include:

- `conversation`
- `incomingMessages`
- `outgoingMessages`
- `messageSequenceNumber`
- `dedupeHit`
- `deliveryLagMs`

These fields are optional and present only for turns that consume or emit conversation events.

## Testing Migration

Use `createTestHarness` for deterministic thread scenarios:

- `accepted | queued | rejected` `SendReceipt` handling
- idempotency replay (`dedupeHit: true`)
- thread close behavior
- session continuity for follow-up messages in the same thread

## Export Changes

Conversation contracts are now exported from `@a2arium/callagent-core` via:

- `public-types/conversation/schemas`
- `public-types/conversation/types`

Migrate any custom conversation typing to these exports.
