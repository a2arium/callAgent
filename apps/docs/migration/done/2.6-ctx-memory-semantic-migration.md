# Migration Guide: `ctx.semantic` → `ctx.memory.semantic` (v2.6)

> [!IMPORTANT]
> `ctx.semantic` has been **removed**.  
> All semantic memory operations now go through `ctx.memory.semantic`.

## Why

Having two surfaces (`ctx.semantic` and `ctx.memory.semantic`) backed by the same database split the mental model. There is now **one place**: `ctx.memory.semantic`.

## API Mapping

| Old (`ctx.semantic`)                         | New (`ctx.memory.semantic`)                     |
|----------------------------------------------|-------------------------------------------------|
| `ctx.semantic.add({ id, value, tags })`      | `ctx.memory.semantic.add({ id, value, tags })`  |
| `ctx.semantic.read({ tag, filters, limit })` | `ctx.memory.semantic.readItems({ tag, filters, limit })` |
| `ctx.semantic.read({ id: 'key' })`           | `ctx.memory.semantic.readItems({ id: 'key' })`  |
| `ctx.semantic.remove('key')`                 | `ctx.memory.semantic.removeItem('key')`          |
| `ctx.semantic.remove({ tag: 'tmp' })`        | `ctx.memory.semantic.removeItems({ tag: 'tmp' })` |
| `ctx.semantic.remove(fn)`                    | `ctx.memory.semantic.removeItem(fn)`             |

## Examples

### Add

```typescript
// Before
await ctx.semantic.add({ id: 'user:prefs', value: { theme: 'dark' }, tags: ['prefs'] });

// After
await ctx.memory.semantic.add({ id: 'user:prefs', value: { theme: 'dark' }, tags: ['prefs'] });
```

### Read

```typescript
// Before
const results = await ctx.semantic.read({ tag: 'prefs' });

// After – note: method renamed to readItems
const results = await ctx.memory.semantic.readItems({ tag: 'prefs' });
```

### Remove by ID

```typescript
// Before
await ctx.semantic.remove('user:prefs');

// After – note: method renamed to removeItem
await ctx.memory.semantic.removeItem('user:prefs');
```

### Remove by filter

```typescript
// Before
await ctx.semantic.remove({ tag: 'temporary' });

// After — counted and predicate-rechecked by capable backends
const { removedCount } = await ctx.memory.semantic.removeItems({ tag: 'temporary' });
```

### Remove by predicate

```typescript
// Before
await ctx.semantic.remove((item) => item.id.startsWith('tmp:'));

// After — deprecated compatibility only; do not use for workflows or claims
await ctx.memory.semantic.removeItem((item) => item.id.startsWith('tmp:'));
```

## Types

Semantic types are now exported from `@a2arium/callagent-types`:

```typescript
import type {
    SemanticAddInput,
    SemanticItem,
    SemanticReadFilter,
    SemanticRemoveFilter,
    SemanticRemoveResult,
    SemanticPredicateFilter,
} from '@a2arium/callagent-types';
```

## Low-level Adapter Methods

The low-level methods on `ctx.memory.semantic` (`get`, `set`, `delete`, `read`, `remove`) remain adapter-level infrastructure APIs. New application code should use `readItems`, single-key `removeItem`, and strict `removeItems`.

## `M.memory.longTerm.semantic`

Unchanged — this refers to the MentalState semantic memory layer and is **not** part of this refactor.
