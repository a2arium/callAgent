# Migration: agent scaffolding (`scaffoldAgent` and CLI)

## What changed

- **`scaffoldAgent`** — programmatic API on `@a2arium/callagent-core` to generate a new agent directory (manifests, `package.json`, `tsconfig.json`, module files, tests).
- **CLI** — package **`bin`** entry `callagent-scaffold` → `dist/scaffold/scaffoldCli.js`.
- **Monorepo script** — from the repo root, `yarn create-agent …` runs the same CLI.

## Who is affected

Authors starting new agents; consumers of `@a2arium/callagent-core` from npm who want the generator.

## Usage

Author-facing steps, flags, presets, and examples live in **[Tutorial: Build your first APLRET agent](../1-tutorial_build_your_first_aplret_agent.md)**. This migration file records **what changed** and the downstream invocation pattern.

Downstream (non-monorepo) script pattern:

```json
"create-agent": "node node_modules/@a2arium/callagent-core/dist/scaffold/scaffoldCli.js"
```

Run from your project root; `--output` is resolved relative to that current working directory.

## Verification

In the generated package: `yarn build`, then `yarn test` (Jest is invoked via paths to the repo root `jest.config.cjs` when scaffolded under `apps/examples/...`).
