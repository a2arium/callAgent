# Migration Guide: LLM History Now at Snapshot Root (v2.3)

> [!IMPORTANT]
> `M.memory.sensory.llmState` is **no longer populated** by the framework. LLM conversation history is now stored at `snapshot.llmState` (the snapshot root). The `Snapshot` type has been updated to reflect this. Agent code is unaffected unless it directly read this internal property.

## Why

APLRET architecture enforces a strict Single-Writer rule (Rule 2): only `Learning` may write to `MentalState`. The framework was silently injecting infrastructure data (raw LLM message payloads) directly into the agent's cognitive tree on every flush. This also violated Rule 7: LLM dialogue tracking is Control State, not Cognitive State.

## What Changed

1. **`M.memory.sensory.llmState` removed** — the framework no longer writes `llmState` into the cognitive tree at any persistence point (`TurnRunner`, `TaskExecutor`, `TaskEngine`).
2. **`snapshot.llmState` is now the canonical location** — the `Snapshot` type (`packages/core/src/loop/types.ts`) has been updated with `llmState?: unknown`.
3. **`attachAndRestoreLLM` now takes an explicit `baseSnap` parameter** — the hidden `(ctx as any).__lastSnapshotBase` side-channel has been removed.
4. **`historyMode: 'stateless'` is now consistently respected** — all persistence paths correctly skip LLM history export for stateless agents.

## How to Migrate

### Case 1 — You never read `M.memory.sensory.llmState` (most agents)

**No action required.** LLM conversation threading continues to work transparently.

---

### Case 2 — Your agent reads `M.memory.sensory.llmState`

If you directly accessed the internal LLM tracking state:

**Before (now broken):**
```typescript
const M = (snap?.snapshot as any)?.M;
const llmHistory = M?.memory?.sensory?.llmState; // undefined after 2.3
```

**After:**
```typescript
import type { Snapshot } from '@a2arium/callagent-core';

const llmHistory = (snap?.snapshot as Snapshot)?.llmState; // typed access
```

---

### Case 3 — You defined a custom `Sensory` type that included `llmState`

**Before:**
```typescript
type MySensory = { llmState?: unknown; lastObservation: unknown };
```

**After:**
```typescript
type MySensory = { lastObservation: unknown };
// llmState is not part of MentalState — it lives at the snapshot root
```

---

### Case 4 — You used `__lastSnapshotBase` in tests

The hidden `(ctx as any).__lastSnapshotBase` property is gone. If you were calling `attachAndRestoreLLM` in tests, pass the snapshot directly as the 4th argument:

**Before:**
```typescript
ctx.__lastSnapshotBase = { llmState: savedState };
await (engine as any).attachAndRestoreLLM(ctx, 'agent-name', M);
```

**After:**
```typescript
const baseSnap: Snapshot = { M, llmState: savedState };
await (engine as any).attachAndRestoreLLM(ctx, 'agent-name', M, baseSnap);
```

---

## If You Want LLM History in Cognition

The framework does not expose the raw LLM payload to agent logic by design. If an agent genuinely needs to reason about past conversation turns, use the standard APLRET pattern:

1. Emit past turns as `internal` observations in `transition`
2. `learning` stores derived insights in `m.memory.episodic` or `m.worldModel`
3. `policy` reads from `MentalState` to decide next steps

This keeps the cognitive tree intentional, auditable, and under single-writer control.
